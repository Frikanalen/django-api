{% trans "What the document contains" %}

{% blocktrans %}TV-Anytime describes a programme separately from its transmissions, so the two are in different tables and joined by a content reference identifier:{% endblocktrans %}

  • {% blocktrans %}ProgramInformationTable describes each programme once — title, synopsis, genre, duration, language, subtitles, the responsible member organization, and still images.{% endblocktrans %}
  • {% blocktrans %}ProgramLocationTable says where it goes out: a Schedule of broadcast events, and an OnDemandService for the programmes we hold online rights to.{% endblocktrans %}
  • {% blocktrans %}ServiceInformationTable describes the two services, {{ linear_service_id }} and {{ ondemand_service_id }}.{% endblocktrans %}

{% trans "Notes for implementers" %}

{% trans "Identifiers are stable" %}
{% blocktrans %}A programme is identified by crid://{{ authority }}/video/<id> and keeps that identifier across requests, so it is safe to store. The same CRID names the programme whether it is on air or in the on-demand catalogue, which is how the two are recognised as one thing.{% endblocktrans %}
{% trans "Times are Europe/Oslo" %}
{% blocktrans %}Every timestamp carries an explicit UTC offset, so it is unambiguous across the summer-time transitions.{% endblocktrans %}
{% trans "Published and actual times" %}
{% blocktrans %}PublishedStartTime is what is scheduled. ActualStartTime appears only once the airtime has passed, and marks the transmission as one we stand behind as having aired; an item still on air has a start and no end. Our playout follows the schedule, so the two agree.{% endblocktrans %}
{% trans "Not everything on air is available on demand" %}
{% blocktrans %}A programme appears as an OnDemandProgram only where we hold the online rights — which excludes, among other things, programmes containing music registered with TONO. Such a programme still appears in the Schedule, because it does still go out.{% endblocktrans %}
{% trans "Absent means unknown" %}
{% blocktrans %}An element we cannot fill is left out rather than guessed at, so treat a missing element as "not stated" rather than as an error.{% endblocktrans %}
